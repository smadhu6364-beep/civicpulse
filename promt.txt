Build a complete React frontend for CivicPulse — a civic issue reporting platform.

Backend is live at: https://civicpulse-backend-503064884117.asia-south1.run.app

Endpoints:
- GET /api/issues/ — list all issues
- POST /api/issues/ — report a new issue
- GET /api/issues/dashboard — dashboard stats
- GET /api/issues/{issue_id} — fetch single issue
- POST /api/issues/{issue_id}/upvote — upvote an issue

Requirements:
- Use Vite + React
- Pages: Home (issue list), Report Issue (form), Dashboard (stats), Issue Detail
- Connect all pages to the live backend — no mock data
- Clean, mobile-responsive UI
- Handle loading states and errors
- Set up in a /frontend folder
